Project Overview
A modern, responsive web calculator built with  HTML, CSS, and JavaScript. It features a clean flat UI aesthetic, smooth entrance animations, custom CSS properties, and robust state-management logic for standard arithmetic operations.

Tech Stack

HTML5: Semantic layout and DOM structure.

CSS3: CSS Custom Properties (variables), CSS Grid, Flexbox, and keyframe animations.

JavaScript (ES6+): Event listeners, DOM manipulation, state handling, and core computation logic.

Key Features

Smooth CSS entrance animation (fadeInScale) that triggers on page load.

Interactive hover and active states for tactile button feedback.

Handles basic arithmetic (+, -, ×, ÷), decimal safety checks, all-clear (AC), and backspace delete (DEL).

Fully responsive layout styled with modern color variables.

How to Run Locally

Clone or download this project folder to your local machine.

Ensure all required files (index.html, style.css, and script.js) are kept in the same directory.

Open index.html directly in any modern web browser, or launch it using a local development server (like VS Code Live Server).
